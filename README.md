# Prayer Times

I made this project to apply what I have learned about using APIs in the frontend. I built it while learning programming fundamentals using JavaScript, and it uses the [Aladhan](https://aladhan.com) API.

# Project Idea

This project is a task from the Advanced JavaScript course by Tarmeez Academy on YouTube.

All the JavaScript logic and HTML were developed by me 100%.
The styling was designed by Claude 100%.

# Learning Outcomes

- Promises
- Error handling
- API calling
- Using `fetch` to call APIs
- Using external packages
